# صوت صلاه (Sout Salah)

Sout Salah is a comprehensive Islamic application designed to help Muslims in their daily worship. It features a rich library of Quran recitations, prayer times, and other essential tools.

## Features

*   **Quran Recitations**: Listen to high-quality audio recitations from renowned Qaris.
*   **Offline Mode**: Download recitations for offline listening.
*   **Background Playback**: Listen to audio while using other apps or when the screen is off.
*   **Favorites**: Save your favorite recitations for quick access.
*   **Guest Mode**: Explore the app without creating an account.
*   **Authentication**: Secure signup and login powered by Supabase.

## Technologies

*   **Flutter**: Cross-platform mobile development.
*   **Supabase**: Backend for authentication and data storage.
*   **Riverpod**: State management.
*   **Just Audio**: Advanced audio playback.
*   **Audio Service**: Background audio support.

## Getting Started

1.  Clone the repository.
2.  Install dependencies: `flutter pub get`
3.  Run the app: `flutter run`
